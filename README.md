# Podcast Gold Miner

Podcast Gold Miner is a local-first command-line application for finding and cutting strong short-form moments from long podcast videos.

This repository currently implements **Milestones 1–6: the complete local production pipeline**. It creates a canonical transcript, discovers and scores candidates, deduplicates and comparatively ranks the final set, cuts accurate MP4 clips, and writes an auditable HTML report and run manifest.

Every invocation appends structured diagnostics to `logs/run.jsonl`. The log contains stage timings, tool paths, media duration, cache decisions, artifact paths, transcript counts, and recoverable errors. It intentionally excludes transcript contents and credentials. Share this file when asking for help verifying a run.

## Cloudflare background worker

The repository also contains a deployable Cloudflare adapter. It keeps the local `goldminer VIDEO` command unchanged, packages it with FFmpeg in a Linux container, and uses Cloudflare Workflows plus R2 to run one asynchronous video job per container instance.

See [docs/CLOUDFLARE_DEPLOYMENT.md](docs/CLOUDFLARE_DEPLOYMENT.md) for architecture, setup, deployment, and a complete test request.

## Automatic transcription with OpenAI

When `--transcript` is omitted, Gold Miner uses the OpenAI Transcription API with `gpt-4o-transcribe-diarize`. Copy the example configuration and put the key in the ignored `.env` file:

```bash
cp .env.example .env
chmod 600 .env
# Edit .env and replace OPENAI_API_KEY= with your new key.
./run-goldminer /path/to/podcast.mp4 --resume
```

The repository launcher loads `.env` automatically. A value already exported in the shell takes precedence. Never commit `.env`, paste its contents into chat, or put a live key in `.env.example`.

Gold Miner splits long recordings into temporary 10-minute mono MP3 chunks, uploads them sequentially for timestamped speaker-aware transcription, offsets returned timestamps onto the complete episode timeline, and deletes each temporary upload artifact. Each successful API response is checkpointed under `transcription_cache/`, so retrying the command reuses completed paid work. The original video stays local and unchanged; the audio chunks are sent to OpenAI for transcription. Set `OPENAI_TRANSCRIPTION_MODEL` only if the replacement model supports `diarized_json` responses with timestamped segments.

## Requirements

- Python 3.11 or newer
- FFmpeg and FFprobe available on `PATH`

On macOS with Homebrew:

```bash
brew install ffmpeg
```

## Install and run on macOS

Apple's bundled `/usr/bin/python3` may be too old for this project. Install a current Python and FFmpeg, then use a project virtual environment:

```bash
brew install python@3.12 ffmpeg
$(brew --prefix python@3.12)/bin/python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install .
goldminer /path/to/podcast.mp4 --transcript /path/to/podcast.srt
```

When returning to the project in a new Terminal window, run `source .venv/bin/activate` before using `goldminer`.

Use a regular install rather than `pip install -e .`. Some current Homebrew Python builds ignore the hidden `.pth` file generated by setuptools for editable installs, which leaves the console launcher unable to import `goldminer`. After changing the source code, rerun `python -m pip install --force-reinstall .`.

If `pip` is unavailable or hangs, use the repository launcher without installing the package:

```bash
./run-goldminer --help
./run-goldminer /path/to/podcast.mp4 --transcript /path/to/podcast.srt
```

The default output directory is `<video-folder>/<video-name>_clips`, beside the source video. Choose another location with:

```bash
goldminer podcast.mp4 --output ./my-run
```

`--top-k` controls the number of final selections. `--resume` reuses completed transcription, discovery, scoring, embedding, and reranking API work when its fingerprint still matches.

Unless `--no-cut` is supplied, each selected range is cut from the original video with a 500 ms handle on each side, clamped to the source duration. Change this with `--handle-ms`. Outputs use stable names such as `clips/01_story_92.mp4`; each is duration-verified and checkpointed for safe `--resume`. Every completed run also writes `report.html` and `run_manifest.json`.

Final clips are limited to 60 seconds by default, including handles. Use `--max-duration SECONDS` to choose a value from 15 through 120 seconds.

## Test

```bash
python -m unittest discover -s tests -v
```

Tests use fake process runners and do not require FFmpeg, network access, or paid services.

## Evaluate editorial quality

Milestone 7 compares generated rankings with moments independently labeled by senior editors:

```bash
goldminer-evaluate path/to/editorial_dataset.json \
  --output evaluations/baseline.json
```

It reports Recall@10, Precision@5, NDCG@10, boundary error, duplicate rate, and run reliability. See `docs/EVALUATION.md` for the dataset format and baseline regression workflow.

# Candidate Discovery Prompt Version 1.0

Act as a short-form content analyst, not a copywriter. Search each overlapping transcript window for stories, lessons, tactical advice, contrarian takes, frameworks, emotional moments, surprises, analogies, strong questions or debates, and memorable statements.

Return only contiguous utterance ID ranges. Preserve the speaker's meaning. Never invent words or combine separate sections. Optimize discovery for recall while omitting housekeeping and obvious filler. Candidate boundaries may be refined in Milestone 4.
